# deckgen QA samples

Generated by `packages/ai/src/deckgen/pipeline.test.ts` when tests run.

Each slide is labeled `system/layout/variant/theme` (example: `editorial/bullets/title-5/ink`).

| File | Quad prefix | Purpose |
|---|---|---|
| `editorial-ink.json` | `editorial/*/ink` | Default editorial pairing |
| `editorial-indigo.json` | `editorial/*/indigo` | Same outline/layouts as ink — ColorTheme swap |
| `swiss-ikb.json` | `swiss/*/ikb` | Default swiss pairing |
| `long-text.json` | `editorial/*/indigo` | Intentional overflow: long thesis → quote, leftover evidence splits bullets |
| `structure-editorial-ink.json` | (geometry only) | Structure snapshot for swap diffs |

ColorTheme hex is registered (`COLOR_THEME_PALETTES`). Pairing:

- editorial → ink | indigo | kraft
- swiss → ikb | signal | lemon

Negative (expected FAIL) fixtures: [`negative/`](./negative/README.md).

## Run

```bash
pnpm exec tsx --test packages/ai/src/deckgen
# or
pnpm test
```

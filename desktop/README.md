# Slim Office desktop

The file home and the presentation editor. It reads and writes `.pptx` on this computer. Documents and spreadsheets are recognized and not opened yet.

Dependencies are the published packages (`@sliiu/present-*` 0.1.2).

```
pnpm install
pnpm dev
```

`pnpm pack:mac` writes a macOS disk image. AGPL-3.0-or-later, same as the packages.
